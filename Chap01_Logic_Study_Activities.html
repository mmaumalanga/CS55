Propositions, Predicates & Arguments

Six sections build from basic propositions up through quantified statements and formal arguments. Each section ends with a quick self-check. Then head to the Quiz for a full scaffolded test, or try the Matching activity to drill vocabulary.

A proposition is a declarative sentence that is either true or false - never both, and never neither. Questions, commands, and sentences with unbound variables are not propositions.

🧩 Worked Example - Is It a Proposition?

Consider four candidate statements: (a) a blank/incomplete line, (b) "It will be sunny tomorrow," (c) "Take out the trash," (d) "Chocolate is the best flavor." Here's the reasoning:

Check"It will be sunny tomorrow" - declarative, and it will turn out true or false. It's a proposition.
Check"Take out the trash" - this is a command, not a statement that can be true or false. Not a proposition.
Check"Chocolate is the best flavor" - it's an opinion, but it's still a declarative sentence with a definite (if subjective) truth value. It's a proposition.
⚠️ Common Misconception

"Opinions like 'Chocolate is the best flavor' aren't real propositions, since truth is subjective." In propositional logic, any declarative sentence that has a definite truth value - even one we can't easily verify, or one that's a matter of opinion - counts as a proposition. What disqualifies a sentence is being a command or question (which can't be true or false at all), not subjectivity.

✍️ Your Turn - Apply It

Given p = T, q = F, and r = F, evaluate p ∨ r and q ∧ r. Show your reasoning, then reveal the answer.

p ∨ r = T ∨ F = T (at least one is true).
q ∧ r = F ∧ F = F (both must be true for AND).
⚠️ Common Misconception

"∨ (or) means exactly one of the two has to be true." That's the definition of exclusive or (⊕), not ∨. In standard logic, ∨ is inclusive or - it's true if at least one side is true, including the case where both are true. T ∨ T = T, not false.

Starting from a conditional p → q, three related statements can be formed:

FormSymbolRelationship to the original
Converseq → pSwaps the antecedent and consequent - not guaranteed equivalent
Inverse¬p → ¬qNegates both sides - not guaranteed equivalent
Contrapositive¬q → ¬pNegates and swaps - always logically equivalent to the original
🌍 Real-World Application - The Rainy Commute

Take the statement: "If it rained this morning, then the train will be late."

Converse: "If the train is late, then it rained this morning." (Could be false - the train might be late for other reasons.)

Inverse: "If it didn't rain this morning, then the train will not be late." (Also could be false, for the same reason.)

Contrapositive: "If the train is not late, then it didn't rain this morning." This one is guaranteed to carry the same truth value as the original statement - that's what makes the contrapositive special.

⚠️ Common Misconception

"A conditional statement with a false antecedent (the 'if' part) must be false." Not so. Compare: "If 4 is a prime number, then 6 is a prime number." Both parts are false, yet the whole conditional is considered true - this is called vacuous truth. A conditional p → q is false in exactly one case: when p is true AND q is false. If the antecedent is false, the conditional is automatically true, no matter what the consequent says.

Tautology

A compound proposition that is always true, no matter the truth values of its variables - e.g. (p∧q)→p.

Contradiction

A compound proposition that is always false - e.g. ¬(p∨q)∧p.

De Morgan's Laws

¬(p∧q) ≡ ¬p∨¬q     ¬(p∨q) ≡ ¬p∧¬q

🧩 Worked Example - Applying De Morgan's Law

Rewrite: "It is not true that the patient has high blood pressure or influenza."

IdentifyThe structure is ¬(BP ∨ Flu) - a negated OR.
ApplyDe Morgan's law: ¬(BP∨Flu) ≡ ¬BP ∧ ¬Flu - the negation "flips" OR into AND and distributes onto each part.
Result"The patient does not have high blood pressure and does not have influenza."

Other common laws include the Commutative law (order doesn't matter: p∧q ≡ q∧p), the Associative law (grouping doesn't matter), the Distributive law (similar to multiplying across parentheses in algebra), and the Absorption law (p∨(p∧q) ≡ p).

A predicate like P(x) is a statement whose truth depends on the value plugged in for x. Quantifiers turn a predicate into a full proposition over a domain (the set of allowed values):

SymbolNameTrue when...
∀x P(x)Universal ("for all")P(x) is true for every x in the domain
∃x P(x)Existential ("there exists")P(x) is true for at least one x in the domain
🧩 Worked Example - Reading a Predicate Table

Domain: {Ann, Ben, Cam, Dave}. The table gives P(x) and Q(x) for each person:

xP(x)Q(x)
AnnFF
BenTF
CamTT
DaveTT

Is ∀x(Q(x)→P(x)) true?

Check eachAnn: Q=F, so Q→P is vacuously true. Ben: Q=F, vacuously true. Cam: Q=T, P=T, so T→T=true. Dave: Q=T, P=T, true.
ConcludeThe implication holds for every person, so ∀x(Q(x)→P(x)) is true.
⚠️ Common Misconception

"A quantified statement like ∃x(x² ≤ x) has a fixed truth value no matter what the domain is." Not true - the domain changes everything. Over the negative real numbers, x² is always positive and x is always negative, so x² ≤ x is never true, making ∃x(x²≤x) false for that domain. Over the integers, x=0 or x=1 would make it true. Always check the domain before evaluating a quantified statement.

✔️ Quick Self-Check

1. ∀x P(x) is true when...

An argument is a list of premises followed by a conclusion. It's valid if the conclusion must be true whenever every premise is true - there is no truth assignment that makes all premises true and the conclusion false.

RuleForm
Modus Ponensp→q, p ∴ q
Modus Tollensp→q, ¬q ∴ ¬p
Disjunctive Syllogismp∨q, ¬p ∴ q
Hypothetical Syllogismp→q, q→r ∴ p→r
🧩 Worked Example - Testing Validity with a Truth Assignment

Is this argument valid?

p ∨ q¬q∴ p ↔ q
TryFrom ¬q, we know q = F. For p∨q to be true with q=F, we need p = T.
CheckWith p=T, q=F: both premises are true. Now check the conclusion p↔q: T↔F = false.
ConcludeWe found a case (p=T, q=F) where every premise is true but the conclusion is false - so the argument is not valid. This single counterexample is enough to disprove validity.
✍️ Your Turn - Translate & Justify (Create)

An argument in English: "Maria brought her resume but she was late for the interview. If Maria did not bring her resume, then she did not get the job. Therefore, Maria did not get the job." Using p = Maria was late, q = Maria brought her resume, r = Maria got the job, write the argument in symbolic form. Then reveal the answer and decide for yourself: does the conclusion actually follow from the premises?

q ∧ p¬q → ¬r∴ ¬r
Notice premise 1 tells us q is true - so premise 2's antecedent (¬q) is false, making premise 2 vacuously true but telling us nothing about r. The conclusion ¬r doesn't actually follow from the premises - a good reminder that translating an argument correctly is a separate skill from judging whether it's valid.
